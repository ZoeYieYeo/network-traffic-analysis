<h1>Project Overview</h1>
This repository documents my hands-on cybersecurity lab in network traffic analysis and network-based threat investigation.
Using Wireshark and other network analysis tools, I'm working with packet captures to understand how network traffic behaves, identify suspicious activity, and investigate different types of attacks.
The goal of this project is to strengthen my networking knowledge and gain more hands-on experience with skills relevant to a Blue Team or SOC Analyst role.

<h1>Tools Used</h1>
<ul>
  <li>Wireshark</li>
  <li>TCPdump</li>
  <li>Linux</li>
</ul>

<h1>Investigations</h1>

| Investigation | Description |
|---|---|
| Malware Traffic Analysis | Analysing suspicious network traffic and looking for signs of malware-related activity. |
| Brute-Force Attack Analysis | Investigating repeated authentication attempts and identifying possible brute-force activity. |
| Port Scan Analysis | Analysing network traffic to identify port scanning and reconnaissance behaviour.
